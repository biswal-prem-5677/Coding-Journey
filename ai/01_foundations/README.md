# Foundations — Mathematical & Theoretical Core

This layer contains the mathematical and theoretical principles that underpin
all modern AI systems.

The goal here is conceptual clarity, not implementation speed.

Topics in this layer explain why learning algorithms work, converge, generalize,
or fail.

## Scope
- Linear Algebra & Tensors
- Calculus & Optimization
- Probability & Statistics
- Information Theory

## Exclusions
- No model training code
- No datasets
- No frameworks

This layer answers: Why does AI work at all?
